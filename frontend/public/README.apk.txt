Drop your Slangcart Android APK build here as `slangcart.apk`
(this folder is served at the site root, so it becomes
https://slangcart.com/slangcart.apk).

The "Download App" buttons on the public landing page and in the
nav point to `/slangcart.apk` by default — change the URL from
/admin/landing → "Download / APK URL" if you host the APK elsewhere
(e.g. on a CDN or GitHub release).
